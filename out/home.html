Questions, answered

Are the tools really free?

Yes. Every tool marked free works without an account, without a watermark and without a trial period.

Are my files safe?

Tools marked “In browser” process your file on your own device; it is never uploaded. Tools that need our server (for example Word to PDF) upload over an encrypted connection and the files are deleted automatically.

Do I need to install anything?

No. Everything works in a modern browser on Windows, Mac, Linux, Android and iPhone.

Is there a file size limit?

Yes, to keep the service fast for everyone. The limit is shown in each tool before you upload.
